# DegenFamous Bingo Mini App

Cosmic neon-themed Telegram Bingo with group multiplayer, USDT tipping buys, tournaments, affiliates, and sweeps/gold coins.

## Features
- Immersive fullscreen Mini App card
- Row purchases via USDT tip forwarding
- Custom rows, patterns, tournaments
- Referral/XP system
- Leaderboard + records API
- Fairness: Manual last-call marking required for wins

## Setup
1. @BotFather → Create bot, enable Main Mini App → Point to frontend URL
2. Deploy backend (Render/Railway) → Add BOT_TOKEN env
3. Add @cctip_bot to groups for tipping

Deploy frontend: Vercel/Netlify
